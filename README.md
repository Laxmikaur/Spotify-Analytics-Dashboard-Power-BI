# Spotify-Analytics-Dashboard-Power-BI

A dynamic and interactive **Power BI Dashboard** built to analyze Spotify streaming data, artist popularity, playlist reach, and music trends through visually appealing insights.

---

## 📌 Project Overview

This dashboard provides a comprehensive analysis of Spotify data using Power BI visualizations and KPIs. It helps uncover streaming trends, track performance, artist distribution, and audio feature analysis.

---

## 🚀 Dashboard Features

### 📊 KPI Cards
- Total Tracks
- Total Artists
- Total Streams

### 🎧 Audio Feature Analysis
- Danceability %
- Energy %
- Valence %

### 📈 Visual Insights
- Top 5 Tracks by Streams
- Top 5 Playlists by Track Name
- Artist Distribution by Mode (Major/Minor)
- Top Artists by Track Distribution

### 🎛️ Interactive Filters
- Filter by Year
- Filter by Mode

---
